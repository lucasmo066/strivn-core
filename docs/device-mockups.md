# Device mockups

The Sahara Grill showcase uses actual website screenshots inside decorative device frames.

- Safari and iPhone: [Magic UI](https://magicui.design), downloaded from the official `safari.json` and `iphone.json` registries on October 7, 2026. The MIT license is preserved in `registry/magicui/LICENSE.md`.
- Local changes to Magic UI: unique SVG IDs for multiple instances, decorative SVG accessibility, and children slots for optimized Next.js images. Safari's toolbar scales independently of its content so the full screenshot keeps its original proportions. The phone reserves space for the Dynamic Island.
- MacBook: a compact adaptation of the lid, perspective, keyboard, speakers and trackpad construction in [Aceternity Macbook Scroll](https://ui.aceternity.com/components/macbook-scroll), available through its free component registry. [Aceternity's license](https://ui.aceternity.com/licence) permits modified components in commercial end products. This is used within the Strivn website, not redistributed as a component product.
- The MacBook uses CSS perspective and a small hover adjustment instead of the source component's long scroll animation. No additional JavaScript library or 3D model download is needed.
- The tablet bezel is a local, decorative frame. Full, unframed screenshots remain available through the gallery's enlarge control.
